Embedding & API Integration Reference

1

URL Pattern

Power BI report links follow the standard workspace format:
https://app.powerbi.com/groups/{groupId}/reports/{reportId}/{section}

2

Token Generation

The portal automatically extracts the groupId and reportId from the URL, calls the Python FastAPI backend service principal, and retrieves a short-lived Power BI Embed Token.

3

AI Context Synthesis

When interacting with reports, page switches, active filters, and slicer selections are debounced and stored page-by-page to generate slide outlines via Anthropic AI.
